# NodeMacro

NodeMacro는 브라우저에서 노드를 연결해 Windows 작업을 자동화하는 로컬 매크로 도구입니다. 단순 입력 반복뿐 아니라 이미지 인식, 조건 분기, 반복, 창 기준 좌표를 조합할 수 있습니다.

## 주요 기능

- React Flow 기반 노드 편집기
- 마우스 클릭·이동·스크롤·드래그와 키보드 입력
- 멀티모니터 이미지 검색 및 검색 영역 지정
- 이미지 조건 분기와 반복
- 창 제목으로 대상 창 선택 및 창 상대 좌표 사용
- 실행 중·완료·오류 노드 시각 표시
- JSON 저장/불러오기와 캡처 이미지 묶음 저장
- 편집기 실행 및 저장 매크로 직접 실행용 배치 파일
- ESC 비상 중단

## 설치

Python 3.10+와 Node.js가 필요합니다.

```powershell
pip install -r requirements.txt
cd frontend
npm ci
npm run build
```

## 실행

루트의 `NodeMacro.bat`를 실행하면 기존 서버를 재사용하거나 새 서버를 시작한 뒤 브라우저를 엽니다.

직접 실행하려면:

```powershell
python backend\main.py
```

브라우저에서 <http://127.0.0.1:8000>을 엽니다.

## 저장 매크로 바로 실행

저장 창에서 **실행용 배치 파일 생성**을 선택하면 다음 구조로 저장됩니다.

```text
scripts/<이름>/
├── <이름>.json
├── <이름>.bat
└── imgs/
```

생성된 배치 파일은 NodeMacro 서버가 꺼져 있으면 시작하고, 켜져 있으면 재사용한 뒤 해당 매크로를 즉시 실행합니다.

## 창 상대 좌표

1. `창 선택` 노드에 대상 창 제목의 일부를 입력합니다.
2. 좌표 노드에서 `창 기준 좌표`를 켭니다.
3. X/Y는 대상 창 왼쪽 위를 `(0, 0)`으로 계산합니다.

창을 다른 위치나 모니터로 옮겨도 같은 창 내부 위치를 조작할 수 있습니다.

## 노드

- 시작, 창 선택, 좌표, 대기
- 이미지 검색, 이미지 조건문
- 마우스 클릭, 이동, 스크롤, 드래그
- 키보드 입력, 반복문

## 구조

```text
backend/   FastAPI API, 실행 엔진, 자동화 노드
frontend/  React + Vite + React Flow 편집기
scripts/   사용자 매크로와 캡처 이미지
```

서버는 기본적으로 `127.0.0.1:8000`에만 바인딩됩니다.
