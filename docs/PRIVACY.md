# D5 Macro 개인정보 처리 안내

D5 Macro 1.0.5는 계정, 원격 서버, 광고, 텔레메트리를 사용하지 않습니다. 매크로 JSON, 화면 캡처, 설정과 로그는 사용자의 컴퓨터에만 저장됩니다.

- 매크로: `문서\D5Macro\scripts`
- 설정·로그·임시 캡처: `%LOCALAPPDATA%\D5Macro`
- 네트워크: 앱 내부 UI를 위해 `127.0.0.1:8000`만 사용

화면 캡처에는 개인정보가 포함될 수 있습니다. 사용자는 저장 폴더에서 직접 확인하고 삭제할 수 있습니다. 제거 프로그램에서 사용자 데이터 삭제를 선택하지 않으면 해당 데이터는 보존됩니다.

동작 녹화를 켠 동안에는 마우스 클릭 위치와 키보드 입력이 로컬 메모리에 기록됩니다. 녹화 결과를 적용하고 매크로를 저장하기 전에는 파일로 저장되지 않으며 외부 서버로 전송되지 않습니다. 비밀번호 등 민감한 정보를 입력하는 동안에는 녹화를 사용하지 마세요.

지원 요청 시 로그나 매크로를 보내기 전에 민감한 내용을 직접 확인해야 합니다. 게시자가 사용자 파일을 자동으로 수집하거나 전송하지 않습니다.
