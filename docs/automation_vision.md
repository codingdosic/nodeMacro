# 지능형 자동화 설계 및 확장 비전

본 문서는 매크로 엔진이 단순 반복을 넘어 상황을 판단하고 유연하게 대처하는 '지능형 자동화' 시스템으로 진화하기 위한 로드맵을 정의합니다.

## 🧠 1. 지능형 자동화 핵심 요소 (Intelligent Core)

### A. 데이터 기억 및 공유 (Variable System)
- **목적:** 매크로 실행 중 발생한 정보를 저장하고 재사용하여 '상태'를 유지함.
- **주요 기능:** Variable Set(저장), Variable Get(불러오기), 전역/지역 변수 관리.

### B. 논리적 판단 및 분기 (Logic & Comparison)
- **목적:** 수치 비교나 텍스트 포함 여부 등 복합적인 조건을 판단함.
- **주요 기능:** Math Node(사칙연산), Comparison Node(크기 비교), String Logic(텍스트 검색).

### C. 시각적 데이터 추출 (OCR - Visual Brain)
- **목적:** 이미지 속의 텍스트나 숫자를 인식하여 데이터화함.
- **주요 기능:** OCR 추출 노드, 숫자 자동 변환 기능.

### D. 유연한 제어 및 복구 (Resilience)
- **목적:** 예외 상황(팝업, 지연) 발생 시 매크로가 중단되지 않고 우회 경로를 찾음.
- **주요 기능:** Try-Catch(실패 시 복구), While/Until Loop(조건 충족 시까지 반복).

### E. 인간다운 동작 모사 (Humanizer)
- **목적:** 고정된 패턴을 탈피하여 자동화 탐지를 방지함.
- **주요 기능:** Random Delay(랜덤 대기), Pixel Offset Randomization(좌표 오차 부여).

---

## 🖱️ 2. 기본 매크로 동작 강화 (Core Interaction)

매크로의 기본 조작 능력을 완성하기 위해 다음의 인터랙션 노드들이 추가되어야 합니다.

### A. 마우스 정밀 제어
- **단순 이동 (Mouse Move):** 클릭 없이 마우스 커서만 특정 좌표로 부드럽게 이동 (Hover 효과 유도).
- **드래그 이동 (Mouse Drag):** 시작점부터 끝점까지 누른 상태로 이동 (아이템 옮기기, 슬라이드 잠금 해제).
- **마우스 휠 (Middle Click / Scroll):** 휠 버튼 클릭 및 상하 스크롤 기능 (웹 페이지 탐색).

### B. 키보드 시퀀스 고도화
- **콤보 입력:** `Ctrl+Alt+Del` 등 복잡한 동시 입력 지원 강화.
- **텍스트 시퀀스:** 클립보드를 경유한 대량의 텍스트 붙여넣기 지원.
