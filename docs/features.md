# 주요 구현 기능 및 기술적 성과 (Progress Log)

## 1. 노드 기반 인터페이스 구축 (MVP)
- **노드 시스템 구현:** 
  - `시작(Start)`, `좌표(Coordinate)`, `이미지(Image)`, `마우스 클릭(Mouse Click)`, `대기(Wait)` 노드 구축.
- **연결 및 순차 실행:** 노드 간의 핀(In/Out) 연결 정보를 해석하여 흐름(Flow)을 제어하는 스레드 기반 `Executor` 구현.

## 2. 지능적 이미지 검색 및 영역 제한 (Phase 3)
- **공간 필터링 (Region Search):** 전체 화면이 아닌 사용자가 지정한 특정 영역(`x, y, w, h`) 내에서만 템플릿 매칭을 수행하여 검색 속도 향상 및 오작동 방지.
- **실시간 미리보기:** 캡처된 이미지를 노드 내부에 즉시 시각화하고, 클릭 지점을 십자선으로 표시하는 대화형 UI 구현.

## 3. 고도화된 입력 및 캡처 시스템 (Phase 4-1) - [NEW]
- **스마트 키보드 노드:**
  - **다중 모드:** 단일 키, 단축키 조합(Hotkey), 긴 문장 타이핑(Typing)을 하나의 노드에서 지원.
  - **실시간 녹화(REC):** `pynput` 리스너를 연동하여 사용자가 누른 키를 자동으로 노드 설정에 입력하는 인터랙티브 환경 구축.
  - **가변 슬롯:** `Ctrl+Alt+Shift+S`와 같은 복잡한 조합을 위해 동적으로 입력 칸을 추가/삭제할 수 있는 UI 설계.
- **지연 및 화면 고정(Freeze) 캡처:**
  - 우클릭 메뉴 등 포커스 이동 시 사라지는 요소를 캡처하기 위해 '3초 지연 후 전체 화면 스캔' 기능 도입.
  - 화면을 일시정지(Freeze)시킨 후 고정된 이미지 위에서 영역을 선택하게 하여 캡처 정밀도 극대화.

## 4. 에디터 안정화 및 사용자 경험 최적화 - [NEW]
- **정밀 좌표 보정 (Origin Anchor):**
  - 에디터 내 패닝(Panning) 시 마우스 좌표와 캔버스 좌표가 불일치하는 문제를 해결하기 위해 원점 추적용 `AnchorNode` 도입.
  - 화면-캔버스 좌표 변환 공식을 통해 어떤 시점에서도 마우스 위치에 정확히 노드를 붙여넣는 기능 구현.
- **안정성 강화:**
  - 노드 삭제 시 UI 핸들러 충돌로 인한 프리징 현상을 삭제 시퀀스 분리 및 예외 처리를 통해 해결.
  - 폰트 깨짐 방지를 위해 모든 이모티콘을 텍스트 기반(RUN, STOP, REC)으로 전환하여 이식성 확보.

---

## 5. 기술적 도전 과제 및 해결 방안 (Portfolio Highlights)
- **좌표계 변환 문제:** 노드 에디터의 줌/패닝 상태에서 붙여넣기 좌표가 틀어지는 현상을 API 도움 없이 '원점 참조 노드'라는 물리적 객체를 통해 수학적으로 역산하여 해결함.
- **비동기 실행 안정성:** 매크로 실행 중 UI가 멈추지 않도록 `threading`을 활용하고, `pynput` 전역 리스너를 통한 즉각적인 비상 정지(ESC) 기능을 구현하여 안전성 확보.
