# 향후 개발 로드맵 (Future Roadmap)

## ✅ Phase 1-3: 핵심 기능 구축 (완료)
- [x] 노드 기반 기본 UI 구축 (Dear PyGui)
- [x] 이미지 캡처 및 좌표 피커 도구
- [x] 목표(이미지/좌표)와 동작(클릭)의 분리 설계
- [x] 제어 노드(반복, 조건문) 및 실행 엔진 고도화
- [x] JSON 데이터 저장 및 불러오기

## 🚀 Phase 4: 사용자 편의 및 지능형 기반 (진행 중)
- [x] **키보드 입력 시스템 고도화**: 단축키 조합 및 실시간 녹화 기능.
- [x] **화면 고정형 캡처**: 우클릭 메뉴 등 복합 상황 대응 캡처 도구.
- [x] **에디터 정밀화**: 패닝 대응 좌표 보정 및 삭제 프리징 해결.
- [ ] **기본 동작 노드 확장**: 마우스 이동(Move), 드래그(Drag), 스크롤(Scroll) 노드 추가.
- [ ] **변수 및 논리 연산**: `Variable Set/Get` 노드 및 `Math/Logic` 비교 노드 구현.

## 🧠 Phase 5: 리소스 최적화 및 지능형 확장
- [ ] **자동 리소스 관리**: 매크로에서 사용하지 않는 `assets` 내 더미 이미지 자동 정리.
- [ ] **OCR 연동**: 화면 속 텍스트를 읽어 변수로 저장하는 지능형 추출 기능.
- [ ] **에러 복구(Try-Catch)**: 실행 실패 시 우회 경로나 재시도 로직 구축.

## 🌟 Phase 6: 패키징 및 고도화
- [ ] **실시간 녹화기(Recorder)**: 마우스/키보드 조작을 즉시 노드 그래프로 변환.
- [ ] **서브 그래프**: 매크로 파일(.json)을 다른 매크로 내에서 모듈로 불러오기.
- [ ] **독립 실행 파일(.exe)**: 일반 사용자용 배포를 위한 패키징.
